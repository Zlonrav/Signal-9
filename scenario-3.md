# СЦЕНАРИЙ И ТЕХНИЧЕСКАЯ ДОКУМЕНТАЦИЯ ИГРЫ «СИГНАЛ-9» (АКТУАЛЬНАЯ ВЕРСИЯ)

## ЧАСТЬ 1: ПОДРОБНЫЙ СЦЕНАРИЙ И ПРОХОЖДЕНИЕ

### ВВЕДЕНИЕ
Игрок выступает в роли автономного ИИ-модуля станции «Сигнал-9». Главная глобальная цель игры — восстановить работоспособность станции и найти ключ-пароль (Соль) для дешифровки сигнала. Управление происходит через выпадающую консоль (`~`) и системный журнал.

### ЭТАП 1: АВТОРИЗАЦИЯ (`login.html`)
1. **Задача:** Нарисовать Трассит (графический ключ).
2. **Решение:** Ключ — слово «ТРАССИТ». Узнать его можно в консоли через `help login` -> переход в `tools.html`, где в режиме «Текст» можно ввести «ТРАССИТ» и посмотреть порядок точек. Затем вернуться и соединить их.
3. **Результат:** Появляется надпись «ДОСТУП РАЗРЕШЕН», ставится `s9_access_granted = true`, переход на `index.html`.

### ЭТАП 2: ЯЗЫКОВОЙ СБОЙ (`index.html`)
1. **Интерфейс:** Глифы трясутся, текст `ERR_DATA`, телеметрия в машинном коде.
2. **Журнал:** Ошибка `AttributeError: 'DigitalBeing' object has no attribute 'human_lang'`. Автоматически открывается консоль.
3. **Решение:** Ввести `system --help`, затем `system --lang human`.
4. **Результат:** `s9_lang_human = true`, страница перезагружается, интерфейс становится на русском.

### ЭТАП 3: ЗАШИФРОВАННЫЙ СИГНАЛ (`index.html` -> `map.html`)
1. **Интерфейс:** Интерфейс на русском. Глифы крутятся, но **подписи под ними — это недешифрованный мусор** (зашифрованный текст). Журнал сообщает, что ключ-пароль отсутствует.
2. **Действие:** В консоли ввести `map`.
3. **Карта:** Узел «БАЗА ДАННЫХ» (Архив) горит красным (`ERROR`). Архив переполнен. Ввести `archive`.

### ЭТАП 4: ОБУЧЕНИЕ АРХИВА (`archive.html` -> `tools.html`)
1. **Архив:** Выдает ошибку буфера. Журнал просит обучить автосохранение в Инженерном терминале.
2. **Действие:** Игрок переходит в `tools.html` (по команде `terminal`). В консоли вводит `help archive` (получает наводку на `archive --traning`).
3. **Обучение:** Вводит `archive --traning` (терминал желтеет). В консоли вводит `archive --traning word`, чтобы получить список из 5 слов (ХАБ, ГЛИФ, ПУЛЬТ, СЕРВЕР, КОНСОЛЬ).
4. **Механика:** Игрок вводит слово в режиме «Текст» (смотрит на эталон), переключает тумблер на «Трассит» и рисует глиф. Система засчитывает **только нарисованный** глиф.
5. **Результат:** После 5 слов ставится `s9_archive_calibrated = true` (терминал синеет). Архив получает 1 базовую фразу.

### ЭТАП 5: НАКОПИТЕЛЬНЫЙ БУФЕР И ОС (`archive.html` -> `os.html`)
1. **Архив:** Игрок заходит в Архив. Видит вкладки «НАКОПИТЕЛЬНЫЙ БУФЕР» и «СЕКТОР ВЕРИФИКАЦИИ».
2. **Ожидание:** В Буфере накапливаются фразы. Сектор верификации выдает «ОШИБКА ВЕРИФИКАЦИИ. КЛЮЧ-ПАРОЛЬ НЕ НАЙДЕН».
3. **Переход:** Как только накапливается 3 фразы (1 базовая + 2 новые), ставится `s9_archive_fixed = true`. ОС на карте становится доступной.
4. **ОС (Щит):** При входе в `os.html` без флага капчи появляется красный вращающийся щит. При клике на него он «трясется» и открывается консоль. Игрок вводит `login --id 0x7f930cb4ddb0` (или через `self --id`). После ввода правильного ID консоль разблокируется, страница перезагружается, открывается доступ к 5 слоям кубитов.
5. **Сбой:** После починки всех проблемных кубитов на слоях 1-4 (и разблокировки 5 слоя) происходит критический сбой. `s9_edr_os_trigger = true`. Переход в EDR.

### ЭТАП 6: EDR И РЕМОНТ ЯДРА (`edr.html` -> `map.html` -> `core.html`)
1. **EDR:** Рамка терминала скрыта, открывается консоль. 3 этапа уравнений с расширенными диапазонами и случайным числом циклов (2-4). Ввод `edr --answer <число>`. При успехе `s9_os_fixed = true`.
2. **Охлаждение:** На карте Ядро желтое. Чтение журнала (5 шагов) запускает таймер на 64 секунды (`s9_core_timer_start`). После перегрева Ядро краснеет (`s9_core_overheated = true`).
3. **Ядро:** Переход в `core.html`. Ввод `help core` (получение уравнений). Решение системы. Ввод `core --position rt [X], lt [-X]...` и `core --position sync`. Ядро зеленеет, `s9_core_fixed = true`, страница перезагружается. Телеметрия разблокирована.

### ЭТАП 7: ТЕЛЕМЕТРИЯ И КЛЮЧ (`telemetry.html`)
1. **Телеметрия:** 4 волны (Белая + RGB). Параметры генерируются случайно при загрузке.
2. **Решение:** Игрок использует `telemetry --read target`, `telemetry --set ...` и `telemetry --toggle ...` (или кликает по названиям волн). Значения ограничены безопасными лимитами (Clamp).
3. **Результат:** Волны синхронизируются, `s9_telemetry_calibrated = true`.
4. **ФИНАЛ (Задел на будущее):** Игрок получает Ключ-Пароль (Соль). При вводе ставится `s9_salt_found = true`. Мусор в глифах превращается в нормальный текст. Архив начинает верификацию.

## ЧАСТЬ 2: СУПЕР-ПОДРОБНЫЙ ЧЕК-ЛИСТ (ДЛЯ ТЕСТИРОВАНИЯ)

### Общие проверки
- [ ] Все страницы открываются без ошибок в консоли браузера (F12).
- [ ] Route Guard в `auth.js` работает (нельзя открыть ОС без Архива, Ядро без ОС и т.д.).
- [ ] Приоритет «Тюрьмы EDR» срабатывает выше Route Guard.
- [ ] Навигация через консоль (`os`, `map` и т.д.) заблокирована, если модуль недоступен.

### 1. Логин и Хаб (`login.html`, `index.html`)
- [ ] Рисование Трассита пускает в игру.
- [ ] `system --lang human` перезагружает страницу.
- [ ] После перезагрузки подписи глифов — это абракадабра (недешифрованный сигнал). В `tools.html` эталонные 5 слов видны нормально, остальные — тоже абракадабра.

### 2. Архив и Терминал (`map.html`, `archive.html`, `tools.html`)
- [ ] `help archive` в консоли дает наводку на `archive --traning`.
- [ ] `archive --traning` делает терминал желтым, `archive --traning word` выводит список из 5 слов.
- [ ] В режиме «Текст» точки нумеруются. В режиме «Трассит» (во время обучения) глиф засчитывается только после ручного рисования.
- [ ] При успехе глиф висит 3 секунды с надписью `"СЛОВО" - ИЗУЧЕНО`, затем экран очищается.
- [ ] После 5 слов терминал синеет, в Архиве появляется 1 базовая фраза.
- [ ] Вкладка «НАКОПИТЕЛЬНЫЙ БУФЕР» работает. Вкладка «СЕКТОР ВЕРИФИКАЦИИ» показывает красную ошибку (пока нет Соли).

### 3. ОС и EDR (`os.html`, `edr.html`)
- [ ] Вход в ОС по команде `os` (когда Архив починен).
- [ ] При входе отображается красный щит. Клик по нему вызывает тряску и открывает консоль.
- [ ] `login --id` работает только в ОС. Консоль разблокируется, страница перезагружается.
- [ ] В ОС 5 слоев кубитов (вкладки сверху). Переключение слоев сопровождается 3D-анимацией (наезд/отъезд).
- [ ] На слоях 1-4: 4 сломанных (красных), 4 запутанных (фиолетовых, с желтыми и зелеными точками пар) и 2 предупреждающих (желтых) кубита.
- [ ] Желтые кубиты через 15 секунд становятся красными.
- [ ] Ввод `os --reset qubit l1r1c1` чинит одиночный кубит. Ввод для запутанного кубита без пары выдает ошибку.
- [ ] Ввод `os --reset qubit l1r1c1 l4r4c4` разрывает связь пары.
- [ ] После починки всех проблем на слоях 1-4 разблокируется 5-й слой (иконка замка исчезает).
- [ ] Починка всех проблем вызывает переход в EDR.
- [ ] EDR не закрывается по тильде (только по крестику/завершению). Навигация заблокирована.
- [ ] В EDR сетка 12x12. Уравнения генерируются с расширенными диапазонами.

## ЧАСТЬ 3: МАКСИМАЛЬНО ПОДРОБНЫЙ ДАМП ЧАТА (ТЕХНИЧЕСКАЯ АРХИТЕКТУРА)

### 1. Структура проекта (Файлы)
- **HTML:** `index.html`, `login.html`, `map.html`, `archive.html`, `tools.html`, `os.html`, `edr.html`, `core.html`, `telemetry.html`, `404.html`, `template.html`.
- **JS:** `auth.js`, `audio.js`, `config.js`, `glyph.js`, `journal.js`, `terminal.js`, `ui.js`, `visual.js`, `loader.js`, `archive.js`, `core.js` (логика Хаба), `cheats.js`, `sync.js`, `os.js`, `edr.js`, `map.js`, `reactor.js`, `telemetry.js`.
- **CSS:** `style.css`, `style-tools.css`, `style-chat-terminal.css`, `style-terminal.css`.

### 2. Глобальные флаги `localStorage` (`s9_...`)
- `s9_access_granted` (Логин пройден)
- `s9_lang_human` (Язык восстановлен)
- `s9_map_visited` (Карта посещена)
- `s9_archive_training` (Терминал в желтом режиме обучения)
- `s9_glyph_<СЛОВО>` (Флаг изучения конкретного слова)
- `s9_archive_calibrated` (Обучение Архива пройдено, 1 фраза в буфере)
- `s9_archive_baseline_count` (Количество базовых фраз, сейчас `1`)
- `s9_archive_fixed` (Архив накопил нужное количество фраз и починен)
- `s9_phrases_data` (Массив фраз в Архиве)
- `s9_salt_found` (Ключ-пароль найден. Отключает шифрование текста)
- `s9_os_captcha` (ID введен)
- `s9_os_qubits_data` (Объект с данными всех 125 кубитов в 3D-сетке)
- `s9_os_fixed` (ОС починена)
- `s9_edr_os_trigger` (Триггер EDR после ОС)
- `s9_edr_os_passed` (EDR пройден)
- `s9_core_timer_start` (Время запуска таймера охлаждения)
- `s9_core_overheated` (Ядро перегрето / Красное)
- `s9_core_fixed` (Ядро починено / Зеленое)
- `s9_telemetry_calibrated` (Телеметрия синхронизирована)

### 3. Механика шифрования (Подменная соль)
- **`js/glyph.js`**: Функция `getWrongLabel(word)`.
  - Если `s9_salt_found === 'true'`, возвращает нормальное слово.
  - Если слово есть в массиве `VOCABULARY` (5 эталонных слов), возвращает его.
  - Для всех остальных слов использует хэш-функцию с солью `7777` и выдает случайный набор кириллицы.
- Применяется в `core.js` (вывод глифов в Хабе), `archive.js` (вывод в буфере) и `tools.html` (вывод не-эталонных слов).

### 4. Логика Терминала (`terminal.js`, `tools.html`)
- **Стартовый экран:** При открытии консоль выводит `[SIGNAL-9 CORE TERMINAL v9.4.2]` и подсказку.
- **Декоративные элементы:** Уголки консоли, сканирующие линии (CSS).
- **Punto Switcher Fix:** `keydown` проверяет `e.code === 'Backquote'`. Если фокус в `input`, консоль не закрывается. `Escape` всегда закрывает консоль.
- **Команды:** `help archive`, `help terminal` выводят наводки. `archive --traning` включает обучение.
- **Режим Трассит:** В `tools.html` засчитывается только ручное рисование.
- **Парсинг ОС:** Команда `os --reset qubit` разбивает аргументы по пробелам и передает их в `window.processOsCommand` (поддерживает 1 или 2 аргумента для пар).

### 5. Логика ОС (`os.js`)
- **Щит:** При отсутствии `s9_os_captcha`, показывается оверлей с красным щитом. Клик по щиту вызывает тряску и открывает консоль.
- **Данные:** Массив `qubits` хранит 5 слоев по 25 кубитов.
- **Генерация:** 4 сломанных (broken), 2 пары запутанных (entangled, пары A и B), 2 предупреждения (warning). Слой 5 заблокирован (locked).
- **Таймеры:** Для желтых кубитов запускается `setTimeout` (15 секунд) на переход в `broken`.
- **Переходы:** При переключении слоев используется 3D-анимация (scale up/down) для создания эффекта полета.
- **Интерфейс:** Вкладки слоев сверху. Цветные точки на вкладках показывают наличие проблем. Запутанные кубиты фиолетовые с желтой (пара A) или зеленой (пара B) точкой.
- **Победа:** Когда все проблемы на слоях 1-4 устранены, 5-й слой разблокируется. При починке всех сломанных кубитов вызывается EDR.

### 6. Логика EDR (`edr.js`)
- **Песочница:** Блокирует консоль, скрывает рамку терминала. Выводит 3 этапа уравнений. Ввод `edr --answer <число>`. При 3 ошибках — новый пример.
- **Сетка:** 12x12 кубитов, визуально повторяющих стиль ОС (черный фон, неоновые рамки).
- **Взлом Шлюза:** 5-значный код. Ввод `edr --answer <5_цифр>`. При успехе `s9_edr_gateway_passed = true`.

### 7. Логика Ядра (`reactor.js`)
- `checkCorePosition` и `syncCore` доступны всегда.
- Если `s9_core_fixed === 'true'`, функции пишут `[OK] ЯДРО СТАБИЛЬНО`.
- После `syncCore` страница перезагружается через 2 секунды (`location.reload()`).

### 8. Логика Телеметрии (`telemetry.js`)
- **Генерация:** `getRandomParams()` генерирует стартовые параметры для всех 4 волн.
- **Clamp:** В `telemetryCommand` при `--set` срабатывает ограничение (freq 0-100, phase -180..180, amp 0-150, offset -125..125).
- **Интерфейс:** Клик по тексту `RED WAVE` / `GREEN WAVE` / `BLUE WAVE` вызывает `toggleWave(color)`.
- **Аудио:** `osc.type = 'triangle'`, фильтр `lowpass` (2000 Гц), `detune = 10`.

### 9. Читы (`cheats.js`)
- `save` / `load <base64>`: работа с сохранениями.
- `fix_lang`: ставит `s9_lang_human`.
- `fix_archive`: выдает флаги обучения и починки, перекидывает в Архив.
- `calibrate_archive`: только калибрует (1 базовая фраза).
- `reset_archive`: чистит все флаги Архива, включая `s9_archive_training`.
- `fix_os`: ставит капчу, чинит кубиты. Если EDR пройден — чинит ОС. Если нет — вызывает EDR.
- `reset_os`: сбрасывает ОС и EDR.
- `reset_core`: сбрасывает Ядро в желтое состояние.
- `reset_telemetry`: генерирует новые волны.
- `clear_memory`: полная очистка `localStorage`.
