# СЦЕНАРИЙ СИГНАЛ-9

## Этап 1: Пробуждение и Сканирование
1. Игрок авторизуется (Трассит), попадает на Главную (Хаб).
2. В Терминале (тильда) вводит `scan`.
3. Терминал: "ИНИЦИАЛИЗАЦИЯ... ТРЕБУЕТСЯ 150% МОЩНОСТИ... КРИТИЧЕСКИЙ ПЕРЕГРУЗ".
4. Активируется флаг `s9_emergency_reactor`. Включается красный режим.

## Этап 2: Починка Энергоядра (reactor.html)
1. Игрок идет на Карту, открывает Энергоядро.
2. В Терминале (ТОЛЬКО на странице реактора) вводит `restore`.
3. Подтверждает `yes`. Терминал говорит, что точка повреждена, нужен `rebuild`.
4. Вводит `rebuild`. Идет ASCII-прогресс (0% -> 100%).
5. Требуется `include = 0XF4AD`, затем `check = 0XF4AD`.
6. Применяет `yes`. Вылазит ошибка: нужен бэкап.
7. Игрок смотрит в Системный Журнал (справа), видит: "Последний бэкап: [Вчерашняя дата]".
8. Вводит `backup = [Вчерашняя дата]`. Подтверждает `yes`.
9. Успех! Флаг аварии снимается, реактор зеленеет, красный режим выключается.

## Этап 3: Архив
Игроку нужно нарисовать 3 любых глифа в Инженерном терминале, чтобы открыть Базу Данных.
